# Frontend Specification – SPIP v1.5

## Purpose

This document defines the frontend enhancements required for SPIP v1.5.

---

# Design Goals

- Maintain existing UI.
- Improve usability.
- Reduce navigation complexity.
- Highlight planning insights.

---

# New Screens

- Finished Goods Workspace
- BOM Viewer
- Dependency Analysis
- Production Risk Dashboard

---

# Finished Goods Workspace

Each FG page shall display:

- Overview
- Forecast
- Inventory
- RM Components
- PM Components
- Production Risk

---

# Material Details

Each material page shall display:

- Inventory
- Planning Availability
- Criticality
- Where Used
- Affected Finished Goods

---

# Dashboard

New widgets:

- FG Health
- RM Health
- PM Health
- Critical Materials
- Production Risk
- Planning Summary

---

# User Experience

The UI shall:

- Reduce unnecessary clicks.
- Clearly display planning status.
- Explain critical conditions.
- Support responsive layouts.

---

# Future Enhancements (V2)

- Interactive Planning
- Drag-and-Drop Scenarios
- AI Copilot
- Natural Language Search
